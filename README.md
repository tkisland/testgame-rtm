# CLICK RUSH

30秒間のクリック数を競う、HTML・CSS・JavaScript だけのウェブゲームです。スマホのタップとキーボード操作に対応し、自己ベストはブラウザーに保存されます。

## ローカルで遊ぶ

Python 3 を使い、リポジトリのディレクトリで実行します。依存パッケージのインストールは不要です。

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

ローカルのブラウザーで `http://127.0.0.1:8000` を開きます。終了は Ctrl+C です。

## GitHub Pages で公開する

1. このファイル一式を GitHub の `main` ブランチに保存します。
2. リポジトリの **Settings → Pages** を開きます。
3. **Source: Deploy from a branch** を選びます。
4. **Branch: main / /(root)** を選び、**Save** を押します。
5. デプロイ完了後、Pages に表示される URL を開きます。

公開 URL の予定: https://tkisland.github.io/testgame-rtm/

GitHub Free では公開リポジトリを利用してください。ソースも公開されるため、秘密のキーや個人情報は保存しないでください。

## 動作確認

- 開始前にクリックしても点数が増えないこと。
- スタート後、クリック・タップ・Space / Enter で点数が増えること。
- 30秒で終了し、その後は点数が増えないこと。
- 「もう一度挑戦」で点数がリセットされること。
- 自己ベストがページ再読み込み後も残ること。
- スマホ幅で画面がはみ出さないこと。
